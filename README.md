# MyPortfolio

A Flutter mobile application presenting two individual student portfolios in one app.

## Features

- View both student profiles
- Display personal and academic information
- Showcase skills and projects
- Add, edit, and delete information
- Persist data between app sessions
- Consume data from an external REST API
- Navigate smoothly between screens

## Technologies

- Flutter
- Dart
- PostgreSQL or local storage (to be determined based on project requirements)
- REST API
- Git and GitHub
